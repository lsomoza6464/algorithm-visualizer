# Debug Visualizer

A web-based JavaScript algorithm visualizer with LeetCode problem support, user authentication, and history tracking.

demo: https://youtu.be/9dPCdn1fgm0

Visualize any JavaScript code with support for arrays, linked lists, trees, and graphs
Automatically load and visualize LeetCode problems
OAuth login with Google
Save your visualizations and track LeetCode problems you've worked on
Syntax highlighting with Monaco code editor
Step through your code execution with interactive D3.js visualizations
